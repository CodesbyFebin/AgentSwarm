# Contributing to AgentSwarm

```bash
git clone https://github.com/CodesbyFebin/AgentSwarm.git
cd AgentSwarm
cargo test --manifest-path rust-core/Cargo.toml
cargo run --manifest-path rust-core/Cargo.toml -- demo
```

Rules: 100% Rust for rust-core, deterministic, fail-closed, no mocks claiming proof. Branch `feat/`, `fix/`, `docs/`. Conventional Commits.
